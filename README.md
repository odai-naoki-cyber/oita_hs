# 大分県 高校スタンプラリー

各校のQRコードをスマートフォンで読み取るとスタンプが押される、Webスタンプラリーです。
参加者はアプリのインストール不要。入口のQRコードからも同じサイトに入れます。

参加校: 大分東 / 宇佐産業 / 久住高原 / 日出総合 / 日田林工 / 三重総合 / 国東 / 玖珠美山 / 佐伯豊南

## 構成

| 画面 | URL | 内容 |
|---|---|---|
| 台紙(参加者) | `/` | 取得済みスタンプの一覧・進捗・コンプリート表示 |
| スタンプ取得 | `/s/<各校のトークン>` | 各校のQRコードの宛先。開くとスタンプが押される |
| ログイン | `/admin/login` | 管理者ログイン |
| 管理画面 | `/admin` | ロゴ登録・色・コメント・QR発行・全体設定・パスワード変更 |

## 動かし方

必要なもの: **Node.js 22.5 以上**(標準のSQLiteを使うため、他の追加インストールは不要です)

```bash
npm install
npm start
```

初回起動時、ターミナルに管理者のユーザー名とパスワードが表示されます(初回のみ)。
ログイン後、管理画面の「アカウント」からパスワードを変更してください。

### 環境変数

| 名前 | 既定値 | 説明 |
|---|---|---|
| `PUBLIC_URL` | `http://localhost:3000` | **QRコードに埋め込まれる公開URL。本番では必ず設定** |
| `PORT` | `3000` | 待ち受けポート |
| `ADMIN_USER` | `admin` | 初回に作る管理者名 |
| `ADMIN_PASSWORD` | 自動生成 | 初回に作る管理者のパスワード |
| `DATA_DIR` | `./data` | DB とロゴ画像の保存先 |

例:

```bash
PUBLIC_URL=https://stamp.example.jp ADMIN_PASSWORD='任意の強いパスワード' npm start
```

## 公開するときの手順

1. スマートフォンから開けるHTTPSのURLを用意する(Render / Railway / Fly.io / VPS など、Node.jsが動く環境)
2. `PUBLIC_URL` にそのURLを設定して起動する
3. 管理画面の「QRコード」タブで、各校のQRを **PNG保存 または 印刷**
4. 各校の受付・掲示場所にQRコードを貼る

> **重要**: `PUBLIC_URL` を設定する前に印刷したQRコードは、`localhost` を指すため使えません。
> 管理画面のQRタブには、宛先が localhost のままのときに警告が出ます。

`DATA_DIR` は再起動しても消えない場所(永続ディスク)にしてください。
Render の無料プランなど、ディスクが消える環境ではスタンプ記録とアップロードしたロゴが失われます。

## 管理画面でできること

- **各校の設定**: 学校名、メイン色、アクセント色、スタンプ取得時のコメント、ロゴ画像の登録
  - ロゴは PNG / JPEG / WebP / SVG(2MBまで)。未登録の間は、校ごとに異なるモチーフの自動生成ロゴが使われます
  - 「自動ロゴに戻す」でいつでも元に戻せます
- **QRコード**: 入口用+各校用を表示、PNG保存、印刷、再発行
  - 「再発行」すると、その学校の古いQRコードは即座に無効になります(貼り替えが必要)
- **全体設定**: タイトル、案内文、コンプリート時のメッセージ、全体の色
- **記録リセット**: 本番前のテストデータを消すときに使います
- **アカウント**: パスワード変更

## 仕組みとセキュリティ

- 参加者の端末はCookieで識別します。同じ学校のQRを何度読んでも、スタンプは1つです
- 別の端末・ブラウザでは、最初からやり直しになります(ログイン不要にしているためです)
- 管理者のパスワードは scrypt でハッシュ化して保存し、ログインは連続5回失敗で10分間ロックされます
- セッションは8時間で失効します。ログアウトすると即座に破棄されます
- アップロードされたSVGに `<script>` やイベント属性が含まれる場合は拒否します

## 注意点

- スタンプの不正取得(QRの写真を共有して離れた場所から取得する等)を完全に防ぐ仕組みはありません。
  必要なら、QRを定期的に再発行する運用や、受付での目視確認と併用してください
- 管理者は1アカウントのみです。複数人で運用する場合は、パスワードを共有してください
- 個人情報は取得していません(Cookieの匿名IDとスタンプ記録のみ)

## ファイル構成

```
server.js            サーバー本体(API・認証・QR生成・ロゴ生成)
public/
  index.html         台紙(参加者)
  stamp.html         QR読み取り後のスタンプ取得画面
  login.html         管理者ログイン
  admin.html         管理画面
  app.css            参加者向けスタイル
data/                実行時に作られる(DB・アップロード画像)
```
